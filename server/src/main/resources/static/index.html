Ranked-choice counter

This server counts elections through the rankedchoice library. Its API:

  • GET /api/methods: the methods and the options each takes, the bundled rulesets, the report formats and the server's limits.
  • POST /api/count with JSON such as {"ballots": "<a BLT or CSV file's text>", "method": "stv", "ruleset": "scottish", "reportFormat": "html"}: the report.
